# SKETCHBOOK

개인 작업물(HTML) 갤러리입니다. 별도의 프로그램 설치나 빌드 과정 없이, 파일을 그대로 깃허브에 올리면 웹사이트가 됩니다.

---

## 1. 먼저 확인해 보기

`index.html` 파일을 더블클릭하시면 브라우저에서 바로 열립니다. 서버가 없어도 갤러리와 상세 화면이 모두 정상적으로 동작합니다.

---

## 2. 작업물 추가하는 방법

작업물 하나를 추가하실 때 하는 일은 아래 세 가지뿐입니다.

### 2-1. 작업물 파일을 넣습니다

`works` 폴더 안에 새 폴더를 만들고, 그 안에 작업물의 `index.html` 을 넣습니다. 이미지나 CSS 등 딸린 파일이 있다면 같은 폴더에 함께 넣어 주세요.

```
works/
├── 001-wave-study/
│   └── index.html
└── 002-paper-figure/       ← 이렇게 새로 만듭니다
    └── index.html
```

폴더 이름에는 한글과 띄어쓰기를 쓰지 마시고, 영문 소문자와 하이픈(-)만 사용해 주세요. 주소가 깨지는 일을 막아 줍니다.

### 2-2. 썸네일 이미지를 넣습니다

`thumbs` 폴더에 목록에서 보일 이미지를 넣습니다. 파일 이름은 작업물 번호와 맞춰 주시면 관리하기 편합니다(예: `002.jpg`).

웹페이지 화면을 담기 좋도록 가로로 긴 16:10 비율(예: 1440 x 900 픽셀)을 권장합니다. 작업물을 브라우저에 띄우고 화면을 캡처하시면 대체로 이 비율에 가깝게 나옵니다. 색이 있는 이미지를 넣으셔도 화면에서는 자동으로 흑백 처리되므로, 굳이 미리 흑백으로 만드실 필요는 없습니다.

### 2-3. `works.js` 에 한 덩어리를 추가합니다

`works.js` 파일을 메모장이나 코드 편집기로 열면, 아래처럼 주석 처리된 예시가 준비되어 있습니다. 맨 앞의 `//` 기호만 지우고 내용을 채우시면 됩니다.

```js
{
  id: "002",                                  // 화면에 SKB—002 로 표시됩니다
  title: "PAPER FIGURE",                      // 마우스를 올렸을 때 나오는 제목
  year: "2025",                               // 연도
  desc: "작업에 대한 설명을 여기에 적습니다.",   // 상세 화면 하단에 표시됩니다
  thumb: "thumbs/002.jpg",                    // 2-2 에서 넣은 이미지 경로
  file: "works/002-paper-figure/index.html",  // 2-1 에서 넣은 작업물 경로
},
```

주의하실 점은 두 가지입니다. 각 줄 끝의 쉼표와 따옴표를 지우지 마시고, 덩어리 전체를 감싸는 중괄호 `{ }` 뒤에도 쉼표를 꼭 남겨 주세요. 화면이 빈 채로 뜬다면 대부분 이 부호가 빠진 경우입니다.

목록에서 위에 적은 작업물이 갤러리에서도 먼저 보입니다. 최신 작업을 앞에 두고 싶으시다면 새 덩어리를 목록 맨 위에 넣으시면 됩니다.

---

## 3. 연락처 바꾸기

`works.js` 맨 아래의 `CONTACT` 부분을 수정하시면 화면 하단 링크가 바뀝니다.

```js
const CONTACT = {
  label: "CONTACT",                 // 화면에 보이는 글자
  href: "mailto:your@email.com",    // 눌렀을 때 이동할 주소
};
```

인스타그램으로 연결하시려면 `label` 을 `"INSTAGRAM"`, `href` 를 `"https://instagram.com/계정이름"` 으로 바꿔 주세요.

## 4. 깃허브에 올리고 사이트로 공개하기

### 4-1. 저장소 만들기

1. 깃허브에 로그인한 뒤, 오른쪽 위 `+` 를 눌러 `New repository` 를 선택합니다.
2. `Repository name` 에 `sketchbook` 을 입력합니다.
3. `Public` 을 선택합니다. 무료 계정은 공개 저장소에서만 사이트를 게시할 수 있습니다.
4. `Create repository` 를 누릅니다.

### 4-2. 파일 올리기

1. 만들어진 저장소 화면에서 `uploading an existing file` 링크를 누릅니다.
2. `sketchbook` **폴더 안의 내용물 전체**를 창으로 끌어다 놓습니다. `sketchbook` 폴더 자체를 통째로 올리시면 주소에 폴더가 한 겹 더 생기므로, 폴더를 열고 안쪽 파일들을 선택해 주세요.
3. 아래쪽 `Commit changes` 를 누릅니다.

### 4-3. 사이트 켜기

1. 저장소 상단의 `Settings` 로 들어갑니다.
2. 왼쪽 메뉴에서 `Pages` 를 누릅니다.
3. `Branch` 항목을 `main` / `/ (root)` 로 지정하고 `Save` 를 누릅니다.
4. 1~2분쯤 기다린 뒤 같은 화면을 새로고침하면 주소가 나타납니다.

주소는 `https://아이디.github.io/sketchbook/` 형태가 됩니다.

### 4-4. 이후 수정할 때

깃허브 저장소 화면에서 `works.js` 를 클릭하고 연필 모양 버튼을 누르면 브라우저에서 바로 고칠 수 있습니다. 수정 후 `Commit changes` 를 누르면 1분 내에 사이트에 반영됩니다.

## 5. 파일 구성

| 파일 | 역할 | 수정 |
|---|---|---|
| `works.js` | 작업물 목록과 연락처 | **여기만 고치시면 됩니다** |
| `works/` | 작업물 HTML 폴더 | 파일을 넣습니다 |
| `thumbs/` | 썸네일 이미지 | 파일을 넣습니다 |
| `index.html` | 갤러리 화면 | 건드리지 않으셔도 됩니다 |
| `work.html` | 작업물 상세 화면 | 건드리지 않으셔도 됩니다 |
| `assets/style.css` | 디자인 | 색이나 여백을 바꾸실 때만 |
| `assets/app.js` | 동작 | 건드리지 않으셔도 됩니다 |
| `.nojekyll` | 깃허브 게시용 설정 | 지우지 마세요 |

## 6. 문제가 생겼을 때

**갤러리가 비어 있고 "NO ENTRIES" 만 보입니다**
`works.js` 의 쉼표나 따옴표, 중괄호가 빠졌을 가능성이 높습니다. 방금 추가한 덩어리를 다시 확인해 주세요.

**썸네일 자리가 비어 있습니다**
`thumb` 에 적은 경로와 실제 파일 이름이 다른 경우입니다. 대문자와 소문자, 확장자(`.jpg` 와 `.png`)까지 정확히 일치해야 합니다.

**상세 화면에서 "ESTABLISHING CONNECTION…" 이 계속 깜빡입니다**
`file` 에 적은 작업물 경로가 잘못되었습니다. 폴더 이름과 `index.html` 파일 이름을 확인해 주세요.

**깃허브에 올렸는데 화면이 하얗게만 나옵니다**
`sketchbook` 폴더를 통째로 올리신 경우입니다. 저장소 첫 화면에 `index.html` 이 바로 보여야 합니다.
